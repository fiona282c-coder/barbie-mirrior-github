# Barbie Mirror

This is the static website for the Barbie Mirror virtual fitting mirror concept.

## Open it locally

Open `index.html` in a browser. The animated usage flow, fading style selector, play/pause style preview, and mobile menu run in the browser with no build step. The original brand logo and slogan "your look your way" are included. The product illustration explains the top-mounted full-body camera and built-in image-processing computer.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `barbie-mirrior`.
2. Upload `index.html` and the `assets` folder to the repository's root. Keep the folder structure.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Choose `main` and `/(root)`, then save.
5. Wait for GitHub to show your Pages URL. It usually has the form `https://YOUR-USERNAME.github.io/barbie-mirrior/`.

The product examples are illustrative; replace them with your real product information and links before using the site as a storefront.
